# 甜筒双狗

两只可以互动的线条小狗桌面宠物，适用于 Windows 10/11（64 位）。

![甜筒双狗预览](docs/preview.png)

## 下载与安装

从 [Releases 页面](https://github.com/LonngLonngwj/icecream-duo-desktop/releases/latest) 下载 `icecream-duo-setup-1.0.0-x64.exe`。运行安装向导时可以选择安装目录。安装后，可通过桌面快捷方式、开始菜单或安装目录内的 `甜筒双狗.exe` 启动。

安装包尚未进行数字签名，Windows 可能显示「未知发布者」或 SmartScreen 提醒。请确认下载地址为本仓库后再决定是否运行。

## 使用

- 单击小狗：打招呼。
- 按住小狗拖动：移动位置。
- 右键小狗或任务栏托盘图标：选择动作、调整大小、暂停动画、切换置顶或退出。
- 双击托盘图标：重新显示小狗。

程序会记住位置、大小和动画偏好。程序本身不联网，也不会自动更新。

## 卸载

在安装主目录运行 `Uninstall 甜筒双狗.exe`，或通过 Windows「已安装的应用」卸载。卸载程序不会主动清除当前用户的偏好设置。

## 从源码构建

安装 Node.js 后，在本仓库运行：

```powershell
npm ci
npm run dist
```

安装包输出到 `dist/`。仓库包含 Electron 应用源码和形象素材，不包含 `node_modules` 或预构建安装包。
